# 小日帳 Pocketday

小日帳是繁體中文的離線記帳 PWA，支援電腦與手機。可用手動輸入、發票掃描或語音登錄收支，並依月份查看分類統計與理財目標。

[開啟小日帳](https://nistd1023.github.io/pocketday/)

## 開始記帳

首次開啟會顯示示範帳本。點上方帳本名稱可切換，或到「帳本管理」建立家庭、旅行或工作帳本。可為每本帳選底色，搭配表情符號或一至三個字自訂圖標，並隨時更名。手動記帳、語音、發票掃描、理財目標、分類與月統計都使用目前選取的帳本。在「語音記帳」說「昨天午餐花了一百二十元」即可辨識日期、項目、金額與分類。遇到多筆金額或無法判斷的資訊，畫面會請你確認。掃描功能可讀取台灣電子發票 QR Code，也可用裝置上的中英文文字辨識讀取收據。

帳本使用瀏覽器的 IndexedDB。公開網站提供程式和示範資料，個人資料由每台裝置各自保存。「資料備份」可匯出與還原 JSON 或 UTF-8 CSV，包含帳本名稱、圖標、收支、發票品項、分類及理財目標。CSV 的「資料類型」欄可在試算表篩選收支、品項或目標。匯入可建立獨立帳本，或明確選擇取代目前帳本的內容。舊版 JSON 仍可匯入。刪除帳本前可下載備份，按「繼續刪除」後需輸入完整帳本名稱，才能按「永久刪除帳本」。更換網址、裝置或瀏覽器前，請先在原帳本匯出，再到新位置匯入。

語音優先使用支援的裝置端辨識。選用瀏覽器語音服務時，音訊可能交由瀏覽器供應商處理。小日帳不保存錄音，也提供文字輸入。使用自己的帳本及發票無須設定 API 金鑰。

## 本機執行

本專案是靜態網站。從專案根目錄執行以下指令，然後開啟 http://localhost:8000/ 。

```sh
python3 -m http.server 8000 --directory docs
```

使用 Node.js 24 執行語音解析與輸入流程測試。

```sh
node --test tests/*.test.mjs
```

在專案根目錄執行 `python3 -m http.server 8001`，開啟 `http://localhost:8001/tests/storage.html` 可在獨立的臨時資料庫驗證舊資料升級、跨帳本隔離、衝突及刪除保護。

## GitHub Pages 部署

在公開儲存庫的 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，指定 `main` 分支和 `/docs` 目錄並儲存。以後推送到 `main` 的網站變更會自動發布。發布進度可在 **Actions** 查看，網址以 **Settings → Pages** 顯示的結果為準。

網站資產與 PWA 使用相對路徑，可放在儲存庫子路徑。修改網站靜態檔案時，一併更新 `docs/sw.js` 的快取版本及相關資產清單，讓已安裝的 PWA 能取得新版。

## 版本

| 標籤 | 內容 |
| --- | --- |
| `v1.0.0` | 收支、發票辨識、分類統計、理財目標與備份 |
| `v1.1.0` | 加入中文語音解析、自動分類與辨識結果覆核 |
| `v1.2.0` | 多帳本管理、自訂圖標、刪除前備份與雙重確認、CSV 匯出與還原 |

v1.0.0 與 v1.1.0 的網站目錄為 `dist/`。目前 `main` 分支使用 `docs/` 供 GitHub Pages 發布。免費字型、QR Code 與 OCR 套件的授權隨附於 `docs/vendor/`。
